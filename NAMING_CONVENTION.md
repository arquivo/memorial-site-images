# Memorial Site Images - Naming Convention

## Convention Rule

Image files follow a naming convention where domain names have dots (.) replaced with underscores (_).

**Format:** `domain_name_tld.extension`

**Example:** `elearning.rcaap.pt` → `elearning_rcaap_pt.png`

## Special Cases

Some files contain hyphens (-) which are preserved as they appear in the original domain names:

- `ad-lisboa.jpg`
- `ccas.min-financas.jpg`
- `disaster-recovery.gif` (disaster-recovery.gov.pt)
- `inst-informatica.png` (inst-informatica.pt)

## Supported Extensions

The convention supports any image file extension:
- `.png`
- `.jpg` / `.jpeg`
- `.gif`
- `.svg`
- etc.
